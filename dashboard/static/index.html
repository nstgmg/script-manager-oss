    일반 설정과 YAML은 같은 job.yaml을 편집합니다. 한쪽에 미저장 변경이 있으면 다른 편집기는 잠깁니다. 저장하면 서로 동기화되며 외부 변경 충돌 시 초안을 유지합니다.

    Output은 표준 경로의 실행별 데이터만 관리합니다. State는 영구 보존하며 Workspace는 프로젝트 공용 공간입니다.

    보존 정책
    최신 ZIP부터 보존 개수를 적용하며 보호 버전은 추가 보존합니다. Output 조건은 하나라도 초과하면 정리합니다.
    

    실제 정리 작업
    Package ZIP 정리는 파일을 영구 삭제하고 메타데이터·배포 이력은 보존합니다. Output 정리는 전용 휴지통으로 이동하며 디스크 공간을 확보하지 않습니다. Output 영구 삭제 기능은 제공하지 않습니다. 사용자가 직접 삭제한 파일은 복구할 수 없습니다.
    미리보기를 실행하세요.
